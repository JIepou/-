# 32‑разрядный учебный микрокомпьютер на базе МПК серии К1804

## О проекте

Данный дипломный проект представляет собой разработку **32‑разрядного учебного микрокомпьютера** с микропрограммным управлением. Устройство построено на основе отечественного микропроцессорного комплекта серии **К1804** (аналоги Am2900). Проект включает полный комплект конструкторской документации: структурную, функциональную и принципиальные электрические схемы, а также микропрограммное обеспечение для вычисления гиперболического синуса.

**Основные особенности:**
- Арифметика в **обратном коде** с аппаратной поддержкой циклического переноса
- Поддержка четырёх методов адресации операндов (прямая, косвенно-регистровая, автоинкрементная, базово-индексная)
- Объём оперативной памяти – **2048 КБ** (динамические БИС К565РУ7)
- Управляющая память – **ПЗУ 556РТ14** (горизонтальное микрокодирование)
- Организован **прямой доступ к памяти (ПДП)** на 4 канала
- Тактовая частота – **8 МГц**

## Цель работы

Разработать архитектуру и схемотехническую реализацию 32‑разрядного микрокомпьютера, предназначенного для изучения микропроцессорных систем, микропрограммирования, динамической памяти и методов адресации в учебных заведениях.

- `PDF/` – пояснительная записка (PDF) и технико-экономическое обоснование
- `Схемы Visio/` – чертежи в формате Visio:
  - Структурная схема (ГУИР.400201.309 Э1)
  - Функциональная схема (ГУИР.400201.309 Э2)
  - Принципиальная схема блока обработки данных (ГУИР.400201.309 Э3)
  - Принципиальная схема банка ОЗУ (ГУИР.400201.309 Э3.2)
  - Вводный плакат (ГУИР.400201.309 ПЛ.1)
  - Заключительный плакат (ГУИР.400201.309 ПЛ.2)
  - Ведомость документов (БГУИР ДП 1-40 02 01 З09 Д1)
  - Спецификация (ГУИР.400201.309 Д2)

- `Шаблоны/` - примеры выполнения файлов
